A physics-based 3D match-3 game with Bio-Architect theme (glass/marble/organic

**Source 2 — Sweepstakes UI Mutation Engine**

- Design token extraction → `bio-architect.css` + `tokens.ts`
- A/B variant generator → 3 GameScreen layout variants, scored and switchable
- UX optimization engine → Bank button prominence + multiplier clarity as primary
  scoring axes for each variant
- Mutation output → Block F patches are the "mutation" into unified layout

**Source 3 — Farkle Frenzy V3 Architecture (locked)**
The existing monorepo, engine, and game rules. Block F must integrate
seamlessly with the A/B-block engine and the E1 server patch.
